# Keaboard Layouts

- ch-fr: Normal Swiss French.
- onishi-chfr: Onishi-inspired Keyboard Layout for Swiss French -> https://o24.works/layout/
- yutaka: Almost the same as Swiss French without deadkeys (`^ + Shift + AltGr`, `! + Shift + AltGr` and `9 + Altgr`, `0 + Altgr` are deadkeys)
- yutaka-jp: Try for japanese, swapped some voyels.
- yutaka-gr: Greek alphabets.
- yutaka-ru: Cyrillic (Russian) alphabets.

I use `yutaka,yutaka-gr,yutaka-ru` and `onisi-chfr` for japanese.
See also my sway script [xkb-switch.sh](https://github.com/ytky110/sway-scripts/blob/master/xkb-switch.sh).
