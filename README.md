# Keaboard Layouts

- ch-fr: Swiss French.
- onishi-chfr: Onishi-inspired Keyboard Layout for Swiss French -> https://o24.works/layout/
- yutaka: Almost the same as Swiss French
- yutaka-jp: Try for japanese, swapped some voyels.

Now I use `yutaka` for latin script and `onisi-chfr` for japanese as a trial.
